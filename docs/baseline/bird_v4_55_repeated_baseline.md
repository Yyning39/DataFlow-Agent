# v5 多次评测基线

## 实验口径

- 同一公开 BIRD Mini-Dev SQLite manifest：11 个数据库、55 题。
- 同一模型：`deepseek-v4-flash`；temperature=0；v4 语义与增强 Guard 开启。
- 同一服务和数据库注册；单题超时 60 秒；每次使用独立输出与 checkpoint。
- 三次结果：`bird_v4_55_latest_eval.json`、`bird_v4_55_repeat2_eval.json`、`bird_v4_55_repeat3_eval.json`。

## 重复运行结果

| 指标 | 第 1 次 | 第 2 次 | 第 3 次 | 均值 | 样本标准差 |
|---|---:|---:|---:|---:|---:|
| SQL 转换/执行率 | 76.36% | 74.55% | 81.82% | 77.58% | 3.78pp |
| 严格结果正确率 | 36.36% | 30.91% | 34.55% | 33.94% | 2.78pp |
| 结果形状匹配率 | 61.82% | 58.18% | 63.64% | 61.21% | 2.78pp |
| 超时率 | 1.82% | 0% | 0% | 0.61% | 1.05pp |
| 平均总延迟 | 9.90s | 6.69s | 6.49s | 7.69s | 1.92s |
| P50 总延迟 | 6.68s | 5.83s | 5.90s | 6.14s | 0.47s |
| P95 总延迟 | 26.58s | 11.30s | 11.46s | 16.45s | 8.77s |
| 平均模型生成耗时 | 6.46s | 6.01s | 6.29s | 6.25s | 0.22s |

三次运行的 Schema fallback 均为 0%，向量 Schema 检索为空率均为 100%；这表明最终 Schema 可用，但向量索引路径仍未发挥作用。

## 基线结论

1. 模型输出具有明显波动，单次结果不能作为版本能力结论；后续 v5/v6 必须使用相同重复次数和统计口径。
2. 结果正确率约 34%，是主要质量瓶颈；模型生成耗时不是主要瓶颈，SQL 执行平均低于 0.2 秒。
3. 结果形状匹配约 61%，应继续处理投影列数与用户意图不一致问题。
4. Schema fallback 虽为 0%，但检索为空率为 100%，下一步优先实现混合关键词/向量召回并重新评估。
