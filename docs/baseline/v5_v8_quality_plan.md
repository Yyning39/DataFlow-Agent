# DB-GPT v5–v8 质量提升计划

## 目标与验收门槛

| 阶段 | 目标 | 验收证据 | 当前状态 |
|---|---|---|---|
| v5 | 重复基线、混合 Schema 召回、语义中间表示 | 三次 55 题统计；线上 `schema_hybrid_*`、`semantic_intent` | 已完成 |
| v6 | 两阶段 SQL review、空结果低风险重试 | Guard 单测、空结果重试模拟、financial 线上回归 | 已完成 |
| v7 | 路由、缓存、token/成本、多轮上下文 | 路由/缓存单测、timings 字段、多轮冒烟 | 进行中 |
| v8 | 图表、权限、多数据源、产品化验收 | 图表 SQL+类型、权限测试、多源测试、前端 ESLint | 进行中 |

## 指标目标

- 严格结果正确率：重复基线均值 33.94%，下一轮目标 ≥45%。
- SQL 转换率：重复基线均值 77.58%，目标 ≥90%。
- 结果形状匹配率：重复基线均值 61.21%，目标 ≥80%。
- Schema fallback：保持 ≤5%；同时把向量检索为空率从当前 100% 降到 ≤20%。
- P50 延迟：保持 ≤7 秒；P95 延迟单独报告，不用均值掩盖长尾。
- token/成本：供应商未返回 usage 时只展示估算，不把估算当作账单。

## 执行规则

1. 每一阶段先做离线单测，再重启服务做线上冒烟。
2. 公开 BIRD 评测固定 manifest、模型、temperature、超时和数据库注册方式。
3. 每个重要指标至少重复三次，报告均值和样本标准差。
4. 不针对单道题硬编码 SQL；业务含义写入可治理语义配置。
5. 任何自动纠错必须是低风险、可解释、可追踪的；复杂歧义要求用户澄清。
